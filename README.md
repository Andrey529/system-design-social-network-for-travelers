# Social Network for Travelers - System Design

Репозиторий по курсу [System Design](https://balun.courses/courses/system_design)

## Функциональные требования

1) Создание постов пользователей с фотографиями, небольшим описанием и привязкой к конкретной геолокации
2) Возможность поставить лайк/дизлайк на посты пользователей
3) Возможность оставить комментарий под постами пользователей
4) Возможность пользователя подписаться на других пользователей
5) Поиск популярных геолокаций
6) Просмотр постов по популярным геолокациям
7) Возможность посмотреть свою ленту, основанную на подписках в обратном хронологическом порядке
8) Возможность посмотреть ленту других пользователей, основанную на подписках в обратном хронологическом порядке

## Нефункциональные требования

### 1) Аудитория приложения

- Количество пользователей - 10'000'000 DAU
- Поведение пользователей

    В среднем каждый пользователь:
    - создает 1 пост 2 раза в месяц
    - прикрепляет к посту 5 изображений
    - оставляет оценки на 5 постов в сутки
    - комментирует 3 поста в сутки
    - читает комментарии под 10 постами в сутки
    - подписывается на 5 других пользователей в месяц
    - ищет популярные геолокации 10 раз в месяц
    - просматривает 10 постов по каждой популярной геолокации
    - просматривает свою ленту раз в сутки по 5 страниц пагинации
    - просматривает чужую ленту 5 раз в сутки по 3 страницы пагинации
    - подписан на 200 других пользователей
- Регионы использования приложения - только страны СНГ

### 2) Особенности приложения

- Сезонности в приложении - сезонность в приложении отсутствует
- Условия хранения данных - данные храним всегда
- Лимиты и ограничения
    - в 1 посте максимально 10 фотографий
    - размер 1 фото не больше 1 MB
    - размер 1 комментария под постом не больше 300 символов
    - в 1 посте описание длиной не больше 1000 символов
    - в 1 посте только 1 геолокация
    - максимальное количество подписок на других пользователей 1'000'000
    - максимальное количество комментариев под постом 1'000'000
    - загрузка постов при просмотре ленты работает через пагинацию в 10 постов
- Временные ограничения
    - создание поста - 3 сек.
    - оценка поста или комментарий под постом - 1 сек.
    - подписка на другого пользователя - 1 сек.
    - поиск популярных геолокаций - 5 сек.
    - просмотр постов по популярным геолокациям - 3 сек.
    - загрузка ленты - 2 сек.
- Доступность приложения - 99,9%
- Совместимость
    - мобильные устройства
    - браузер

## Расчет нагрузки

### 1. Посты

#### 1.1. Чтение поста

```
DAU = 10'000'000
просматривает свою ленту раз в сутки по 5 страниц пагинации по 10 постов
просматривает чужую ленту 5 раз в сутки по 3 страницы пагинации по 10 постов
просматривает 10 постов по каждой популярной геолокации 10 раз в месяц

RPS(read) = 10'000'000 * (5 * 10 + 5 * 3 * 10 + 10 * 10 / 30 ) / 86'400 =
=  10'000'000 * (50 + 150 + 3) / 86'400 = 100 * 200 ~= 20'000
```

```
RPS(read) = 20'000
Размер данных = 1 KB
Traffic(read) = 20'000 * 1 = 20'000 KB = 20 MB/sec
```

#### 1.2. Создание поста

```
DAU = 10'000'000
1 пост 2 раза в месяц
RPS(write) = 10'000'000 * 2 / 86'400 / 30 ~= 7
```

```
RPS(write) = 7
Размер данных = 1 KB
Traffic(write) = 7 * 1 = 7 KB/sec
```

### 2. Изображения

#### 2.1. Получение изображений

```
RPS просмотра поста = 20'000
В среднем пользователь просматривает по 3 фотографии в посте
RPS(read) = 20'000 * 3 = 60'000
```

```
RPS(read) = 60'000
Размер данных = 1 MB
Traffic(read) = 60'000 * 1 = 60'000 MB = 60 GB/sec
```

#### 2.2. Загрузка изображений

```
прикрепляет к посту 5 изображений
RPS создание поста = 7
RPS(write) = 7 * 5 = 35
```

```
RPS(write) = 35
Размер данных = 1 MB
Traffic(write) = 35 * 1 = 35 MB/sec
```

### 3. Оценки

#### 3.1. Чтение оценок

Приходит вместе с информацией о посте

#### 3.2. Оставление оценок

```
DAU = 10'000'000
5 реакций в сутки
RPS(write) = 10'000'000 * 5 / 86'400 ~= 500
```

```
RPS(write) = 500
Размер данных = 50 B
Traffic(write) = 500 * 50 = 2500 B/sec
```

### 4. Комментарии

#### 4.1. Чтение комментариев

```
DAU = 10'000'000
читает комментарии у 10 постов в сутки
в среднем в каждом посте по 5 комментариев
RPS(read) = 10'000'000 * 50 / 86'400 ~= 5000
```

```
RPS(read) = 5000
Размер данных = 350 B
Traffic(read) = 5000 * 350 = 1'750'000 B/sec = 2 MB/sec
```

#### 4.2. Оставление комментариев

```
DAU = 10'000'000
3 комментария в сутки
RPS(write) = 10'000'000 * 3 / 86'400 ~= 300
```

```
RPS(write) = 300
Размер данных = 350 B
Traffic(write) = 300 * 350 = 105'000 B/sec = 105 KB/sec
```

### 5. Подписки

#### 5.1. Подписка на пользователей

```
DAU = 10'000'000
5 подписок в месяц
RPS(write) = 10'000'000 * 5 / 86'400 / 30 ~= 15
```

```
RPS(write) = 15
Размер данных = 50 B
Traffic(write) = 15 * 50 = 750 B/sec
```
